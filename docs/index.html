1 What this is

Trevius operates an assistant that helps an Instagram Business or Creator account owner handle Direct Messages and comments without missing a lead. It watches for new messages, drafts a reply, and sends nothing until the account owner has approved that exact text.

The one rule the assistant never breaks: no message reaches a lead with wording the owner hasn't personally seen and approved.

2 What data it touches

To do this, the assistant reads, only from the Instagram Business/Creator account the owner has connected through Meta's official Instagram API:

DataWhy
Direct message text and sender's Instagram-scoped IDTo detect a new lead and draft a reply
Comment text on the owner's own postsSame, for public comments
Which messages have already been handledSo the same message isn't surfaced twice

It does not read the owner's personal messages, other accounts' private data, or anything outside the connected professional account's own inbox.

3 How it's used

  • Scoring how urgent a message looks (a plain keyword check — no message content leaves the assistant's own process for this step).
  • Drafting a candidate reply, shown to the owner before anything is sent.
  • Sending the owner-approved reply back through Meta's official API — never through any unofficial or scraped channel.

Nothing collected here is used for advertising, profiling, or resale. It exists only to run this one assistant for its own connected account.

4 Where it's stored

The assistant is self-hosted: it runs on infrastructure the account owner controls, not on a Trevius-operated server shared across customers. The only thing kept on disk is a short list of message IDs already handled, so a re-check doesn't reopen a resolved conversation — no message content is retained beyond what's needed for the live conversation in progress.

5 Sharing with third parties

Message content is shared with exactly one third party: the AI provider used to draft a reply, solely to generate that draft. It is not sold, not used to train third-party models beyond that provider's standard processing, and not shared with any advertiser, data broker, or unrelated service.

6 Your control over it

The account owner can disconnect the assistant from their Instagram account at any time through Meta's own Business Integrations settings, which immediately revokes its access. Deleting the assistant's local state file removes the short list of handled-message IDs described above.
